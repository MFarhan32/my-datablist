# my-datablist

A production-ready MERN Datablist clone with:
- JWT authentication + refresh tokens
- List/record CRUD operations
- CSV upload and parsing
- Duplicate detection
- Bulk delete and exports
- Socket.io real-time updates
- React + Tailwind responsive UI

## Quick start

### Backend
```bash
cd server
cp .env.example .env
npm install
npm run dev
```

### Frontend
```bash
cd client
cp .env.example .env
npm install
npm run dev
```

### Docker
```bash
docker-compose up --build
```
